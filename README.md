## Technologies

These are the technologies I used across my Frontend Mentor challenges:

- **Frameworks:**

  [Next.js](https://nextjs.org/) - React framework for building full-stack web applications

- **Markup and Styling:**

  [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) - Markup language for documents displayed in a web browser

  [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) - Specifies the presentation/styling of a document written in a markup language

  [Tailwind CSS](https://tailwindcss.com/) - CSS framework allows to build custom designs without leaving the HTML

- **Programming Language:**

  [TypeScript](https://www.typescriptlang.org/) - Strongly typed programming language that builds on JavaScript, giving better tooling at any scale

- **Runtime:**

  [Node.js](https://nodejs.org/en) - Cross-platform JavaScript runtime environment that lets developers create servers, web apps, command line tools and scripts

- **Libraries:**

  [React](https://react.dev/) - JavaScript library for web and native UIs

  [clsx](https://www.npmjs.com/package/clsx) - Utility for constructing className strings conditionally

  [focus-trap-react](https://www.npmjs.com/package/focus-trap-react) - React component that traps focus

  [React Icons](https://react-icons.github.io/react-icons/) - Bundles popular icon sets as React components

  [Hero Icons](https://heroicons.com/) - SVG icons by the makers of Tailwind CSS

- **State Management:**

  [Redux Toolkit](https://redux-toolkit.js.org/) - Manage global app state with Redux, with less boilerplate

- **Developer Tools:**

  [React Developer Tools](https://react.dev/learn/react-developer-tools) - Extension for inspecting the React component tree and debugging props and state

  [Redux Developer Tools](https://github.com/reduxjs/redux-devtools) - Extension for tracking Redux state changes and replaying actions during debugging

  [Lighthouse](https://developer.chrome.com/docs/lighthouse) - Creates audits for performance, accessibility, progressive web apps, SEO, and more

- **Testing Frameworks and Libraries:**

  [Jest](http://jestjs.io/) - JavaScript testing framework

  [React Testing Library](https://testing-library.com/) - React components testing library

  [Playwright](https://playwright.dev/) - Automation library for E2E testing

- **Accessibility:**

  [NVDA](https://www.nvaccess.org/) - Open-source screen reader for Windows

- **Version control and CI/CD:**

  [GitHub](https://github.com/) - Version control system for tracking code changes and managing project history

  [GitHub Actions](https://github.com/features/actions) - CI/CD platform built into GitHub that automates workflows on every push or pull request

- **Design:**

  [Figma](https://www.figma.com/) - UI design and prototyping tool used to create wireframes, mockups, and design systems collaboratively
